# Local API contract

All paths start `/api`. JSON errors: `{error:{code,message,details?}}`. IDs are opaque; timestamps are ISO UTC. Unknown request fields fail. Local single-user, same origin. No authentication/tenant claims.

`GET /bootstrap`: `{report_types:[], snapshots:[], assets:[], programs:[], jobs:[], capabilities:{...}, demo:true}`. Lists may use full records (small local installation). Snapshot records are the shape in native-contract.md plus `digest`. Source assets: `{id,filename,digest,size,media_type,created_at,status:'usable'|'blocked',profile:{format,row_count,columns,sheets?,regions?,sample_rows?,warnings:[],eligible_roles:[]},demo}`. Programs: `{id,report_type_id,name,version,digest,state:'candidate'|'published',coverage:[{id,label,kind,status}],decisions:[{id,question,alternatives:[{value,label,consequence}],resolution}],evaluation:null|{passed,checks:[{name,passed,detail}],digest,created_at},limitations:[],input_contract,created_at}`. Report type: `{id,name,description,active_program_id,created_at,demo}`.

- `POST /report-types {name,description?}` -> report type and candidate `{report_type,program}`. Current adapter is explicitly quarterly regional revenue; this is not arbitrary automated learning.
- `POST /assets` multipart `file`, optional `role` -> immutable inspected asset. Accepted CSV/XLSX/DOCX/PDF; only supported tabular assets can bind `transactions`. `GET /assets/{id}` and `/download`.
- `POST /report-types/{id}/examples {report_asset_id,source_asset_ids,period,corpus_role:'authoring'|'development'|'reserved'}` -> example. Explicit evidence ingestion; no model is implied.
- `GET /programs/{id}`. `POST /programs/{id}/evaluate {expected_digest}` -> program with persisted independent checks. `POST /programs/{id}/decisions {decision_id,resolution,expected_digest}` -> program with a new digest (evaluation invalidated). `POST /programs/{id}/publish {expected_digest}` -> published program. Unresolved decisions, stale evaluation or code drift return 409.
- `POST /report-runs {report_type_id,asset_id,period,idempotency_key}` -> job. Period fields: label,start,end_exclusive,comparison:{start,end_exclusive},timezone,as_of (ISO aware datetime).
- `GET /jobs/{id}` -> `{id,kind,status:'queued'|'running'|'completed'|'blocked'|'failed'|'cancelled',stage,steps:[{stage,at}],result:{snapshot_id?|export_id?},error:null|{code,message},created_at,updated_at}`. `POST /jobs/{id}/cancel {}` persists cancellation. Poll until terminal; no fake progress percentages.
- `GET /report-snapshots/{id}` -> snapshot. `POST /report-snapshots/{id}/revisions {expected_revision,node_id,text,reason}` -> new snapshot (new ID and revision, old immutable). Only editable rich-text commentary may be changed; numeric assertions and causal claims trigger review, computed blocks cannot be edited.
- `POST /report-snapshots/{id}/accept {expected_revision}` -> new accepted snapshot, audit record. Required blockers cannot be overridden through this endpoint. Human review acknowledgment is explicit.
- `POST /exports {snapshot_id,format:'docx'|'xlsx'|'pdf'|'pptx',policy:'compatible'|'strict',idempotency_key}` -> job. Compatible allows explicitly declared static representations. Strict XLSX blocks pending native pivot application certification. Draft exports are labelled drafts.
- `GET /exports?snapshot_id=...` -> array `{id,snapshot_id,format,filename,digest,status,manifest,created_at}`. `/exports/{id}/download` actual bytes; `/exports/{id}/manifest` JSON. `/report-snapshots/{id}/audit` downloads snapshot, source identities, validation and audit JSON (raw sources excluded).

Source upload is not report generation. Export never calls the runtime. Exact period/source/program identity governs run idempotency. The bundled demo is labelled synthetic in records and output metadata.
